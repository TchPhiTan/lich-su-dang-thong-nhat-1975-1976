## 🎨 DESIGN SYSTEM

### Bảng màu
```
--red-primary:   #C62828   (đỏ chính — hero, heading)
--red-dark:      #7B0000   (đỏ đô — gradient end)
--gold:          #FFD700   (vàng — số liệu nổi bật)
--bg-base:       #0D0D0D   (nền chính)
--bg-surface:    #1A1A1A   (card bg)
--text-primary:  #F5F5F5
--text-muted:    #757575
```

### Typography
- Display: `Playfair Display` (700-900)
- Heading/Body: `Be Vietnam Pro` (400-700) — hỗ trợ tiếng Việt
- Số liệu lớn: `Bebas Neue` (64-96px)
- Caption: `Be Vietnam Pro` 12px italic

### Animations
- Hero load: fade-in slide-up 400ms
- Timeline: alternating slide-in (Intersection Observer)
- Stats: counter từ 0 → số thực khi scroll vào
- Cards: hover translateY(-6px) + glow màu trụ cột
